# Fili.VSCode2026 Pack

Visual Studio 2026's look and feel for VS Code, in one install.

| Extension | What it brings |
|---|---|
| [Fili.VSCode2026](https://marketplace.visualstudio.com/items?itemName=FiliArrochada.fili-vscode2026) | All fifteen Visual Studio 2026 themes, Solution Explorer's file icons, Fluent toolbar icons, and an optional one-command Visual Studio layout |
| [C#](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp) | C# language support; its Roslyn server supplies the semantic colours the themes match to Visual Studio |
| [C# Dev Kit](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csdevkit) | A real Solution Explorer — the **C# Project Details** view in the Explorer: the solution, its projects and their Dependencies, as in Visual Studio |
| [Visual Studio Keymap](https://marketplace.visualstudio.com/items?itemName=ms-vscode.vs-keybindings) | Visual Studio's keyboard shortcuts (F12, Ctrl+K Ctrl+C, F5, F10, F11, ...) |

After installing, pick a theme with `Ctrl+K Ctrl+T` (for example **Fili.VSCode2026 Dark**), and
run **Fili.VSCode2026: Apply Visual Studio 2026 Layout** from the Command Palette for Visual
Studio's window layout.
